# OntoFlow

**以业务对象与工具规约约束 LLM 的多步工具编排。**

研究原型：LLM 根据任务、工具说明和当前对象选择下一次调用；本体检查器核验其对象绑定和调用条件，通过后执行真实函数并记录结果。核心设想是“Agent 即软件，动态本体即 Harness”。

这里的“动态”主要指执行过程中对象、状态与证据的更新；并非已实现自动演化的通用本体学习系统。

## 快速开始

需要 **Node.js 24+**。没有第三方运行依赖，无需 `npm install`。

```sh
git clone https://github.com/Shotsuke/ontoflow.git
cd ontoflow
cp .env.example .env
# 在 .env 填写自己的 DASHSCOPE_API_KEY；不要提交该文件。
npm test
npm run build
npm start
```

打开 http://127.0.0.1:4173 。服务默认仅监听回环地址，可用环境变量 `PORT` 调整端口。

- **无需密钥**：查看工具、本体对象、独立约束演示和 [已验证运行的只读回放](http://127.0.0.1:4173/?replay=verified)。
- **需要密钥**：点击“LLM 决策一步”或“自主编排”，发起真实模型调用，会消耗模型服务额度。
- **命令行运行**：服务启动后执行 `npm run live`，结果写入忽略提交的 `runs/`。可用 `ONTOFLOW_URL` 指向其他本机端口。
- `.env.example` 配置 DashScope 和 `qwen3.6-plus`。其他兼容接口可设置 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`；具体模型需支持代码使用的 Chat Completions 请求格式。
- 若需要代理，使用自己环境中的 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`，并设置 `NODE_USE_ENV_PROXY=1`；仓库不预设代理或远端服务器。

## 本体如何参与

1. **对象与映射**：概念定义输入输出含义，模拟表字段映射为对象属性；对象有独立身份、实验归属和来源证据。
2. **工具规约**：函数声明输入/输出对象类型、对象方法归属、调用条件和结果映射。
3. **执行前检查**：核验类型、对象是否存在、实验归属、同曲线质量证据、单位、训练/留出隔离和集合完整性。
4. **执行后更新**：结果成为新对象，保留输入血缘与调用证据。模型的文字宣告不能替代任务完成判据。
5. **模型上下文**：提供按身份组织的当前对象状态、对象来源和最近四次调用反馈。检查失败只描述该次输入，不将历史错误当成当前全局事实。

没有生产用的固定工具优先级或预录执行路线。`tests/fixture.mjs` 的确定性流程仅用于数值和检查器测试，不被客户端或模型 API 引用。模型失败时会暂停，不以脚本替代决策。

图中节点是工具，潜在边从规约推导，显示衔接条件。单条边只是某一输入的候选来源，多输入和关系条件仍需联合检查；红色执行边由实际成功调用的对象血缘生成。图的排版不参与决策。

## 独立合成科学任务

反应动力学小任务：4 个温度，各 2 条浓度曲线，每条 12 个观测；6 条训练、2 条留出。数据由一级反应与 Arrhenius 方程独立生成，未使用任何真实业务或其他平台的模拟数据。

提供 10 类对象和 10 个函数，其中普通最小二乘与 Theil–Sen 稳健估计可以产生相同的速率对象类型。工具选择、处理顺序和对象集合由模型决定。最终报告需关联同源模型与通过阈值检查的留出验证。

目前函数实现预装，注册表单模拟规约登记；尚未提供任意源码上传、隔离执行或通用条件语言。检查器和计算函数在浏览器中运行，不能据此宣称防篡改或生产级可信执行。模型接口运行于服务器，密钥不进入客户端。

## 工程验证，而非基准成绩

33 项自动测试覆盖数值计算、对象关系、单位、集合、未知证据、替代算法、无效提议、取消/过期响应以及 API 契约。

`examples/` 同时保留 2026-11-13 的成功和失败记录：

| 运行 | 模型 | 模型请求 | 成功函数调用 | 拦截 | 结果 |
|---|---|---:|---:|---:|---|
| 1 | qwen-plus | 60 | 51 | 9 | 达到上限，未完成 |
| 2 | qwen-plus | 49 | 46 | 2 | 响应错误，未完成 |
| 3 | qwen-plus | 60 | 46 | 14 | 达到上限，未完成 |
| 4 | qwen3.6-plus | 39 | 37 | 2 | 完成并通过留出验证 |

成功运行得到约 40.3068 kJ/mol 的活化能、0.8992% 的留出相对误差，依赖深度为 9。调用总数不等于推理链深度。期间修改过上下文表达并切换模型，因此这些记录不能用来证明因果收益、估计稳定成功率或作为模型公平对比。浏览器视觉和点击验收尚未完成。

## 结构

```text
client/engine.js       对象、规约、条件检查、数值实现、图关系
client/controller.js   模型请求生命周期、取消与请求上限
client/app.js          工作台、对象、工具与执行证据
api/model.js           服务端模型连接与 JSON 决策协议
scripts/build.mjs      构建带内嵌资源的 Worker ESM
scripts/run-live.mjs   真实模型集成运行
server.mjs            本机 Node 服务与只读回放
examples/             纯合成的四轮执行记录及汇总
tests/                检查器、数值与模型接口测试
```
